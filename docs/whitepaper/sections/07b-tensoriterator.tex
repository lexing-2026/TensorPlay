\section{TensorIterator：广播、类型提升和并行归约}
\label{sec:tensoriterator}

\subsection{问题：一次迭代抽象}

\texttt{add} 的逐点 \ac{cpu} 内核必须处理三个正交问题：(i) 广播、(ii) 类型提升和 (iii) 非连续跨步。每个内核手写四个嵌套循环将重复 80%。 TensorIterator 是可重用的执行模板：内核仅提供 \texttt{dst[i]=func(src[i])}。

CPU 实现提供了完整的可重用迭代器路径，而 CUDA 内核目前手写索引；统一这两条道路仍然是未来的工作。

\begin{tpdef}[Definition (TensorIterator)]
\emph{TensorIterator} 是用于元素和归约内核的可重用执行模板。给定操作数 $(t_1,\dots,t_n)$ 和输出 $o$，其构建管道（七个步骤，\S\ref{sec:tensoriterator}）计算通用形状 $S$、通用数据类型 $D$ 和每个操作数步长，以便最内层循环可以在连续路径上以单位步长执行。然后，内核仅提供标量函子 $\mathrm{dst}[i] = f(\mathrm{src}_1[i],\dots,\mathrm{src}_n[i])$ 以及可选的向量化变体；广播、提升和跨步重新排序均已在循环运行时解决 \emph{before} ，因此热路径不包含针对这些问题的每个元素分支。
\end{tpdef}

\subsection{构建管道：七个步骤}

:

\begin{lstlisting}[caption={seven steps.}, label=lst:tibuild]
void TensorIteratorBase::build(Config& cfg){
  is_reduction_=cfg.is_reduction_;
  populate_operands(cfg); mark_outputs(); compute_mem_overlaps(cfg);
  compute_shape(cfg); mark_resize_outputs(cfg); compute_types(cfg);
  if(!fast_set_up(cfg)){ compute_strides(cfg); reorder_dimensions(); allocate_or_resize_outputs(); coalesce_dimensions(); }
  for(auto& op: operands_) op.data = op.tensor().data_ptr();
}
\end{lstlisting}

\begin{enumerate}[leftmargin=1.2em]
\item \textbf{populate\_operands:} 将 \texttt{Tensor} 移入 \texttt{OperandInfo}，记录 \texttt{data} 和 \texttt{stride\_bytes}。
\item \textbf{compute\_shape}：广播规则\texttt{size==1}广播，否则相等；保留 \texttt{0} 大小。
\item \textbf{compute\_types} ( 折叠 \texttt{promoteTypes},)：如果 \texttt{promote\_inputs\_to\_common\_dtype}，则通过 \texttt{op.tensor.to(common\_dtype)} 创建临时变量；如果 \texttt{cast\_common\_dtype\_to\_outputs}，则分配临时输出。
\item \textbf{compute\_strides + reorder\_dimensions:106}：插入排序按步幅升序变暗，减少前面的变暗；如果 \texttt{enforce\_linear\_iteration} 则禁用。
\item \textbf{coalesce\_dimensions:530}：合并 \texttt{shape[n]*stride[n]==stride[n+1]} 相邻的暗淡。
\item \textbf{allocate\_or\_resize\_outputs}: \texttt{empty(shape, dtype, device)} if \texttt{resize\_outputs}.
\item \textbf{post:} 填充 \texttt{op.data = tensor.data\_ptr}。
\end{enumerate}

当所有操作数共享形状且连续时，会折叠为 \texttt{shape[0]=numel}。

\subsection{类型促销格子}

定义严格格：

\begin{lstlisting}[caption={lattice (abridged).}, label=lst:promote]
DType promoteTypes(DType a,DType b){
  if(a==b) return a; if(a==Undefined||b==Undefined) return Undefined;
  if(isComplexType(a)||isComplexType(b)){
    if(a==ComplexDouble||b==ComplexDouble) return ComplexDouble;
    if(a==ComplexFloat||b==ComplexFloat) return isFloatingType(other)? ComplexDouble: ComplexFloat;
  }
  if(isFloatingType(a)||isFloatingType(b)){
    if(a==Float64||b==Float64) return Float64; if(a==Float32||b==Float32) return Float32;
    if(a==Float16 && b==BFloat16) return Float32; // avoid mutual loss
  }
  if(a==Bool) return b; if(b==Bool) return a;
  if(a==Int64||b==Int64) return Int64;
}
\end{lstlisting}

枚举 20 多种类型（\texttt{UInt8}、\texttt{Float32}、\texttt{BFloat16}、\texttt{ComplexDouble}、\texttt{QInt8}、...），带有 \texttt{isComplex} 谓词和 \texttt{elementSize}。结果写入 \texttt{Edge::grad\_dtype} 以进行向后投射。

\subsection{并行和缩减}

\texttt{for\_each(loop, grain=GRAIN\_SIZE)} 分派到 \texttt{parallel::parallel\_for}（自定义线程池，\texttt{GRAIN\_SIZE=32768}）。 \texttt{parallel\_reduce} 选择 \texttt{two\_pass\_reduction} 作为单元素输出（每个线程缓冲区，然后 \texttt{final\_reduce}） vs.（\texttt{find\_split\_dim}、\texttt{narrow}、\texttt{foreach}）。

\subsection{内核接线}

:

\begin{lstlisting}[caption={Pointwise wiring.}, label=lst:pointwise]
template<Func> Tensor unary_op_kernel(const Tensor& self, Func func, VOp vec){
  Tensor out = empty(shape,dtype,device); Tensor contig=self.contiguous();
  bool vec_ok = vecunary::vec_ready() && vec!=None && (dtype==Float32||Float64);
  switch(dtype){ case Float32: { auto s=contig.data_ptr<float>(); auto d=out.data_ptr<float>();
    if(vec_ok) parallel_for(0,n,8192, [&](b,e){ vec_run(vec,prm,s,d,b,e); });
    else parallel_for(0,n,8192,[&](b,e){ for(i=b;i<e;i++) d[i]=func(s[i]); }); break; } ... }
  return out;
}
\end{lstlisting}

\ac{cuda} \texttt{PointwiseKernels.cu} 目前手写 \texttt{blockIdx*blockDim} 网格步幅循环，没有 TI——已知的重复留给未来的工作。
