\section*{Appendix: Notation and Central Listings}

\paragraph{Notation.}
\texttt{path:line} means the file relative to the repository root; is line~49 of that file, and \texttt{path:line--line} is an
inclusive range. Code listings are verbatim excerpts with at most whitespace folding; the caption gives the context. Tables enumerate normative values (key numbers, artifact names, trimmed axes) rather than
illustrative samples.

\paragraph{Central entities.}
For a reader who wants the shortest path through the core, the
central definitions are: the dispatch table (\texttt{array<atomic<KernelFunction>,13>}),
the key enum, the tensor object model (\texttt{Tensor}/\texttt{TensorImpl}/\texttt{Storage}),
the autograd graph (\texttt{Node}/\texttt{Edge}/\texttt{GraphTask}/\texttt{InputBuffer}/\texttt{Engine}
with the \texttt{SavedVariable} guard and the \texttt{VariableVersion} counter),
the anomaly mode, the grad/inference TLS modes, the profiler's
\texttt{OpRecord}/\texttt{GpuTimerPair} stack, the vmap keys at offset 9, and
the two YAML registries behind code generation. Each chapter opens with a figure that
places its entities on the four-pillar map.
