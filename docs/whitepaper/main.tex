\begin{abstract}
\setlength{\parindent}{2em}
TensorPlay 是以清晰性与系统严谨性为核心构建的深度学习框架。框架确立由 \textbf{p10}（张量、存储与分发）、\textbf{tpx}（自动微分）、\textbf{stax}（编译中间表示）与原生扩展 \textbf{\_C} 构成的四支柱体系，实现层次分明、依赖单向、链接期强约束的清晰架构，在保持实现精炼的同时完整覆盖分发、自动微分、向量化与剖析等关键机制，为教学、研究与系统探索提供了可读、可复现的基座。

本文系统呈现其关键具体机制：13 槽位 \texttt{DispatchTable} 与 \texttt{Composite} 回退、\texttt{TENSORPLAY\_LIBRARY\_IMPL} 静态注册、\texttt{TensorIterator} 七步流水线、显式有向无环图（无 Tape）、基于 \texttt{sequence\_nr} 的 \texttt{ReadyQueue} 调度、\texttt{SavedVariable} 版本守卫、偏移 9 的 \texttt{Vmap} 键，以及 \texttt{OpRecord}/\texttt{GpuTimerPair}/\texttt{Cupti}/\texttt{Nvtx} 构成的多维剖析技术栈。

\medskip
\noindent\textbf{关键词：}深度学习框架、分发、自动微分、向量化映射、重分发、剖析器、代码生成、张量迭代器
\end{abstract}
