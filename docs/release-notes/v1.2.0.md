# 亮点 Highlights

- **macOS MPS 后端正式成形**：从设备 / 分配器骨架扩展到完整 LLM 训练推理栈——
  Metal shader 库、flash attention（prefill / 单遍 decode / 两遍 decode）、SDPA 路径选择、
  嵌入与 embedding bag、RMSNorm 前向/反向、融合优化器（Adam / AdamW / SGD foreach）、
  AMP 梯度缩放、top-k 采样、随机工厂、稀疏 COO、量化算子、GEMM / 卷积一应俱全；
  macOS 轮子默认启用并配备独立算子基准与 CI 性能下限。
  启动路径同步重写：连续派发共用一个 encoder 与一次 commit、编译图按
  "计算 + 形状"签名跨调用复用、以流锁替代队列跳转；在 macOS 15 虚拟 M1 上与
  同轮配对的对照运行时相比，长组 95 例总体 **1.12x**（几何平均）、胜率 **79%**。
- **低比特量化全链路**：原生 INT4 / INT2 / 1-bit 权重算子与 `8da4w` / `8da2w` / `8da1w`
  行列量化内核，AWQ 扩展到 int2，FP8 动态推理，BitNet b1.58 三元权重与 STE 训练；
  直接 int4 tensor-core GEMM（pipelined 与 mma 双路径）默认改走 cuBLAS 反量化通道。
- **量化算子族成体系（CPU + CUDA）**：packed affine dtype、量化线性 / 卷积 / 池化 /
  归一化 / 激活 / 嵌入 / 循环 / 张量运算全覆盖；eager QAT、FX graph-mode
  （`prepare_fx` / `convert_fx` / `fuse_fx`）、后端配置框架与融合注册表齐备，
  并提供 one-call 自动量化工作流。
- **ROCm 成为默认发布通道**：CDNA MFMA flash attention 与 wave64 安全 WMMA 回退，
  HIP 工具链构建修复成体系；ROCm 轮子进入 release / nightly 默认矩阵并发布到
  独立 ROCm pip 索引。
- **可解释性套件 `tensorplay.lumen`**：经典归因（IG / DeepLIFT / LRP / SHAP / TCAV）、
  稀疏自编码器、交叉层 transcoder、attribution graphs、feature circuits、logit lens、
  因果追踪与激活修补，以及图重写引导的反向传播与编译消融执行。
- **量子模拟模块 `tensorplay.quantum`**：状态向量与密度矩阵、门表线路与变分拟设、
  测量与采样、噪声信道、Lindblad 主方程、参数位移梯度，配套本地门 / 振幅概率 /
  Kraus / Pauli 信道等原生内核。
- **脉冲神经网络 `tensorplay.snn`**：融合 LIF / IF 神经元内核、15 个原生代理梯度、
  多步 BPTT、`SpikingConv2d` / 时间折叠批归一化等深层 SNN 模块。
- **评估套件 `tensorplay.metrics`**：分类 / 回归 / AIGC / 音频 / 检索等域指标，
  状态式 `Metric` 与函数式双形态；融合双输入归约让 MSE / MAE 在 CPU 上数倍加速。
- **编译器符号形状下沉**：符号尺寸贯穿 Stax 捕获、正向/反向图复用、视图与方差梯度，
  动态布局以运行时守卫落地；稀疏 addmm 自动微分与嵌入稀疏反向路由补齐。
- **Vulkan 后端从"能跑"到"能跑 LLM"**：buffer / linear 与纹理双存储成为对等路径并按操作数
  实际存储分派，逐元素 / 比较 / 选择 / 归约 / softmax / cumsum / 归一化 / 索引 / 工厂 /
  随机与采样全面覆盖；FP16 存储与 GEMM、int8 GEMM、w4a16 权重内积、设备端
  per-tensor 与 block-wise 仿射反量化、rotary embedding 与 SwiGLU、带因果掩码的
  三阶段 SDPA 与"一次扫键"的长上下文 flash 路径全部落地。RTX 3090 上
  1024³ GEMM 0.963→0.473 ms、长键 decode 约 8x、KV cache 单行追加
  2 348→24.7 µs、词表 16384 的 top-k 采样 8.5→1.2 ms。

# 新特性 New Features

## macOS MPS 后端

- **后端骨架**：设备 / 分配器 / 工厂 / copy / add，`tp.mps.is_available()` 入口；
  macOS wheel 默认启用。
- **基础算子面**：逐元素、激活、归约、随机工厂、`cat` / `stack` / `embedding`、BLAS、
  `all` / `any`；损失族（mse / l1 / smooth_l1 / huber / bce / nll）；归约 / 视图 / 池化 /
  归一化 / 索引 / 量化算子；`batch` / `group` norm、conv2d、`argmax` / 极值归约。
- **Metal shader 库与量化**：shader 化 int4 / int8 量化矩阵乘、per-channel
  quantize / dequantize、`make_per_channel_quantized_tensor`、per-tensor affine 量化填充。
- **稀疏 COO 后端**：工厂、`coalesce`、格式转换、mm、add/mul、sum、addmm。
- **排序与结构算子**：scan、sort、bucketize、dropout、三角算子全部 shader 化。
- **LLM 推理/训练栈**：RMSNorm（含 fused 反向）、embedding 前向/反向、embedding bag、
  融合优化器（Adam / AdamW / SGD foreach）、top-k 采样、SDPA 路径选择、flash attention
  prefill、单遍 / 两遍 decode attention、masked SDPA。
- **GPU 随机工厂**：rand / randn / arange / eye / randint / linspace / logspace /
  randperm / multinomial 直接落到 GPU shader，生成器一路传到内核。
- **AMP**：梯度缩放与非有限检查内核。
- **高级内核**：M5+ cooperative-tensor GEMM 与 conv2d、张量相等性检查。
- **性能路径**：索引类算子迁移到 Metal shader，降低 CPU 桥接开销。
- **本轮补齐的 shader 路径**：`item` 内核、越界索引经流错误缓冲上报（嵌入与访问内核
  在设备侧定范围，不再回宿主扫描）、块拷贝实现 `cat` / `gather`、3D 网格与 shader 掩码
  索引、threadgroup 内的末轴扫描、log-sum-exp 归约折成一次启动、分组归约与评测归一化
  合并单趟、行极值与其谓词同趟给出、`clamp` 连续浮点单趟、除法走广播 shader、
  `erf` / `floor` / `ceil` / `round` / `sign` 改由一元 shader 服务，超越函数改用硬件近似。
- **启动与内存路径**：一个流区间共用一个 command buffer 与一次 commit（连续 shader
  派发、图派发、池化 / 卷积 / cat / stack 都不再逐算子提交）、编译图按"计算 + 形状"
  签名跨调用复用并把 addmm 的两级标量缩放折进矩阵乘图、以流锁替代队列跳转、
  嵌入行经设备地址空间以 16 字节访问流式读取、栅栏同步过的回读免掉第二次队列等待、
  宿主遍历存储前显式 `synchronizeHostAccess()`（工厂填充、nll 归约、仿射量化、
  稀疏 COO 组装、宿主到设备拷贝、索引归一化）。

## Vulkan 后端

线性（buffer）存储与纹理（image）存储成为对等的两条路径：算子按操作数的实际存储分派，
结果落在操作数所用的存储类里，跨存储类的 `copy` / `clone` 负责迁移负载。

- **推理与反向（本周期早段）**：GRU / LSTM 推理、`narrow`、randn 工厂、erf、
  `native_dropout`、激活反向（elu / selu / softplus）、max / avg pool2d 反向、
  layer_norm 反向（组合矩单趟）；显存池 + vec4 广播二元算子、工作组扩大、
  设备显存不足时回退线性存储。
- **逐元素与算术**：一元 / 二元 / 标量 / 参数算子与三元 `where` 覆盖 buffer 存储，
  广播感知的线性二元算子、原地标量与 `pow`、`clamp`、原地 `gelu`，以及半精度的
  一元 / 二元 / 三元 / 参数算子全族。
- **比较、选择与形状**：`compare` / `compare_scalar`、`masked_fill`、`flip`、`permute`、
  `glu` / SwiGLU、`cumsum`、`roll` / `rot90`、`triu` / `tril`、`diagonal`、
  整数 `split`、零元素张量。
- **归约与归一化**：按轴归约、全局极值与 `argmax` / `argmin`、方差与组归约、
  `softmax` / `log_softmax`、`rms_norm`（单派发）与 `layer_norm`、`batch_norm`
  （线性复合路径），以及它们在半精度负载上的对应形态。
- **索引与视图**：`embedding`、`index_select`、`index_copy` 行散布、`gather`
  （含由设备索引列表指名的两类存储）、`cat`（buffer 输出可混合纹理输入）、
  `slice` / `select` 走跨步 gather、超过图像轴上限的排序与 gather、
  上传的 Bool 平面按稠密字节负载读回。
- **工厂、随机与采样**：`arange` 等宿主填充工厂、buffer 上的 `random_fill` 与
  随机流填充、`rand`、`bernoulli_`（张量概率）、`multinomial`（逆 CDF，带替换）、
  全词表 logits 采样与温度 / top-k / top-p 合成一个 token 采样器。
- **半精度与低比特**：FP16 存储与 GEMM、tiled FP32 / FP16 矩阵乘、批量 `bmm`
  （含半精度）、decode 矩阵-向量的分裂归约路径（含半精度与无纹理形态）、
  w4a16 权重量化线性（含设备整型码与单行快路径）、int8 GEMM 与 int8 `rms_norm`、
  设备端 64 位码转换、宽于一字的元素与码在存储中的落位、
  per-tensor 与 block-wise 仿射反量化在设备端完成、`rotary_embedding`
  （含半精度与线性 cos/sin 表）。
- **注意力**：SDPA 融合为三阶段 GPU 流水线并支持因果掩码与分组头广播；
  长上下文改走"一次扫键"的 flash 路径——每个 workgroup 负责一个头的 8 行查询，
  把键块就地折叠进该行的运行最大值 / 指数和 / 值累加器，调用中最大的对象是其下方的
  17 KB 共享块，无需图像、无 subgroup 操作、无宽于 32 位的元素偏移；
  分数无纹理形态或超过四百万通道时取此路径，其余形状仍走融合的纹理链。
- **KV 缓存**：静态缓存的序列轴追加改由 `index_copy_` 承担，索引列表留在设备侧。

# 改进 Improvements

- MPS 后端按算子族组织为独立 Objective-C++ / Metal 文件，沿用仓库"每文件一族内核、
  一个注册宏"的可读结构，便于学习并行计算与原型验证。
- 前端热路径：低比特反量化广播、缓存解包模式；INT8 权重前向保证 contiguous。
- 量化内核：整型向量裁剪、浮点斜率 PReLU、量化窗口复用与 packing 向量化、
  空间量化均值融合、体素池化向量化、尾块精度保持。
- 稀疏：CPU `sparse_addmm` 非零循环 4x 展开、per-ISA 向量化、量化嵌入 packing 优化。
- 随机 / 生成器：量子模块中的 Haar 随机酉与状态、全局相位读取。
- 前端分派：候选规则先剔除缺少必填关键字参数的项，拼写重复出现时保留单匹配快路径；
  设备摘要里的后端名按其真实拼写给出。
- 内核分发几何：Vulkan 稠密算子按"每线程一个向量"或四宽向量分发，小启动铺满多个
  threadgroup；MPS 的逐元素与行归约链跨网格 / 跨 simd 组跨步访问，谓词行在决定它的
  那个元素处停止，单位步长操作数走专门的稠密算术与选择路径。
- 派发缓存：每线程记住最近解析的稠密 shader pipeline 与最近一次乘法构造的图视图，
  池化 / 卷积图与归约图按签名跨调用复用。
- 基准口径：链路型用例按"结果所占存储"而非输入定预算，配对模式下两种运行时在同一
  进程内交错采样，同一条记录里的两个最小值共享同一宿主窗口。

  直走 `index_copy_`；线性 buffer 的 `gpu_numel` 不再套用纹素打包对齐（此前
  末轴非 4 倍数的形状会被放大，`32768x10` 负载报出 393 216 个元素，staging 按此尺寸
  拷贝会越过源负载并按堆布局随机崩溃），staging 拷贝另按逻辑字节数封顶；读映射用 invalidate 而非 flush；
  sort 改在 device-local scratch 上按 tile 工作组驱动；int8 GEMM 纹理布局、
  LLM 算子 ABI 与 rotary 布局、SDPA 分裂内存合并与其派发修正；buffer 上的采样输入
  遇到字节打包 dtype 明确拒绝而非静默错值；连续 buffer 张量的 `reshape` 走元数据视图；
  原地 buffer shader 的绑定号连续编号并拒绝非连续的绑定声明。
- **量化**：量化编码 / 输出张量契约、归一化布局与 strided 工厂、packed 存储与网格在
  设备转换 / 拷贝中保留、池化累加器与转换位宽、tanh / sigmoid / hardtanh / relu6
  舍入与向量精度、动态整数算术、检查点设备与 dtype 元数据、channel 元数据校验、
  混合 dtype 提升前先比较、默认量化字激活数学；三维量化窗口的池化轴计数读错（#79）、
  packed 参数按条退役、需要流式搬运权重或嵌入表时结果按操作数的存储归还。
- **编译器**：CUDA graph 捕获加固、STAX 复数处理、不支持的编译 double backward 明确
  拒绝（与 v1.1.0 梯度局限文档一致）、动态视图 stride 的形状约束复用、节点位置与整数
  形状边界保留、符号标量输入输出、形状提示与静态事实区分。
- **构建 / 跨平台**：ROCm 工具链拼写（图捕获探针、设备侧 fault、分组 GEMM 命名空间、
  卷积方案数组尺寸、注意力调度、cuBLASLt 调优开关、运行时加载器、生成源重映射）；
  SVE256 下量化向量回退、MSVC `std::popcount` 可移植拼写、OpenBLAS ILP64 运行时
  LAPACK 解析；生成的 shader 源里反斜杠转义、共享 shader 头在 Metal 源中保持合法、
  注册表依赖清单跟进新增的 shader 源、拒绝非连续的 shader 绑定号、
  分组 foreach 的元数据尺寸改为编译期守卫。
- **前端**：`qat.dynamic` 循环导入、hub 原生导出与 `__all__` 去重、packed 仿射检查点、
  二元准确率状态与标量微归约、图梯度函数自动处理 `requires_grad`；MPS 走 autocast
  分派、MPS 设备类型导出到 Python 绑定、张量的 `mps()` 设备助手、MPS 张量创建不再
  借用 CUDA 专用的 pinned staging。

# 性能 Performance

口径：静默机器 min-of-window。Vulkan / CUDA 数值取自 RTX 3090（空闲与共享占用两种情形
分别标注）；MPS 数值取自 macOS 15 虚拟 M1 CI runner 上的配对基准——两种运行时在同一进程
内逐对交错采样，长组 95 例、chain 1，比值为"对照运行时 / 本项目"。

- **MPS 配对基准**：总体 **1.12x**（几何平均，闸门下限 1.00x），胜率 79%（75/95），
  逐对比值中位 1.11x、97%。领先项：`norm[1M]` 5.33x、`logsumexp[1024x1024]` 2.86x、
  `masked_fill[1M]` 2.82x、`bucketize[1M]` 2.30x、`searchsorted[1M]` 2.14x、
  `sort-dim1[1024x1024]` 2.11x、`gather[1024x1024]` 2.05x、`argsort-dim1` 1.85x。
- **MPS 启动路径**：四个 shader 启动助手停止逐算子闭合 encoder 之后，chain 16 的几何平均
  由 1.180x 升到 1.493x，达到 1.00x 以上的用例 42 → 46，我方单用例时间中位数
  226.7 → 200.7 µs；三角算子由图执行改走 shader 后，1M 元素从 3.9 ms 降到 0.37 ms；
  索引类算子从 CPU 桥接迁到 Metal shader，随机工厂全部 GPU 化，融合优化器 / RMSNorm /
  flash attention 直接以 GPU 内核执行。
- **Vulkan GEMM**：tiled 32×32 子块经共享内存暂存（33 浮点行距避开 bank 冲突），
  512³ FP32 0.171 → 0.096 ms、1024³ 0.963 → 0.473 ms，与 CUDA 基线的差距收窄到约 4x，
  FP16 与 addmm 走同一条路径；decode 单行（M=1）1024×1024 线性路径 0.066 ms，
  快于同形状 FP16 matmul 的 0.072 ms，单层 decode 演示约 0.41 ms/token。
- **Vulkan 注意力**：SDPA 融合为三阶段流水线并把 softmax 折进 pv 行走一遍，
  1024 键的 decode 约 8x；"一次扫键"路径在 B=1 / Hq=32 / Sq=2048 / D=128、
  键长为查询 4 倍的形状上，因果 201 ms 对非因果 336 ms（此前两者无差别）。
- **Vulkan 采样、排序与索引**：V=16384、top_k=50 的端到端采样 8.5 → 1.2 ms（直接在有序
  logits 上做温度 / softmax / top-k / top-p，省掉全词表 softmax 一遍）；
  sort V=16384 1.42 → 0.12 ms、top-k k=50 0.98 → 0.11 ms；KV 缓存追加的单行
  `index_copy_` 从 2 348 µs 到 24.7 µs（范围检查移入 shader），此前它把整条
  生成循环拖到 1.4 ms/token；栅栏同步过的回读免掉第二次队列等待，
  单次回读 3.6 ms 中收回 1.5 ms。显存池复用 + vec4 广播二元算子、
  layer_norm 反向的组合矩单趟与工作组的扩大沿用本轮早前的改动。
- **CUDA 索引族**：`masked_select` p50 0.5138 → 0.2421 ms，满载交错时单调用挂钟
  2.46 → 0.25 ms（设备内核自身 0.24 ms）；非末维扫描 660.5 → 226.5 µs；
  `nonzero` 改两级块偏移扫描、`index_add_` / `index_copy_` / `index_fill_` 原地写目标、
  `searchsorted` 免掉 staging 输出填充、`bincount` 值域扫描并行化、分组 foreach
  每次启动塞进更多块、rank-2 行广播算术改用扁平的 row-per-block 内核、
  整型键的单次游程排序不再做转换遍历。
- **低比特 GEMM**：int4 默认走 cuBLAS 反量化路径；pipelined direct int4 tensor-core
  与 mma 内核；int8 `_int_mm` 经 cuBLASLt tensor core；AVX2 BF16 int4 内核。
- **量化算子向量化**：int8 mm 融合 rowwise 量化与 rescale、单趟 rowwise quantize、
  量化归约 / 池化 / 嵌入 / 软最大 / 循环门 / cat 的 SIMD 路径、CPU `sparse_addmm`
  非零循环 4x 展开与 per-ISA 分派。
- **指标**：融合双输入归约单趟计算 SSE / SAE，MSE / MAE 相对参考实现数倍加速
  （AVX2，8 线程，详见 README Benchmarks 节）。

# 被追踪的回退 Tracked Regressions

- 三项 MPS 启动侧实验在链路型用例上回退，已各自 revert，不在发布路径上：逐点算子
  "编码即提交"（该虚拟 M1 runner 为每个额外 command buffer 收约 90 µs，
  `add-relu[8x16x32]` 的配对比值从 0.9715 掉到 0.7751、`div` 从 0.9770 掉到 0.8064，
  长组胜数 62/95 → 51/95）、提交前轮询 command buffer 状态、以及 clamp 每线程四宽向量
  的长游程形态。发布路径保持"一个流区间共用一次 commit"，链路型回退请先怀疑宿主编码
  成本而非缺失的提交。
- `clamp[1M]` 仍落后对照约 3%–7%：四宽×四向量、四宽×一向量与标量索引三种几何都落在
  同一区间，同一条向量路径上的 `abs[1M]` 已经打平，判断为指令级差异而非派发开销，
  不再重复尝试启动几何。
- 本轮长组的落后项为 `round[1M]` / `prod[1M]` 0.96x、`clamp[1M]` /
  `cumsum-dim1[1024x1024]` 0.97x，都贴着该 runner 上约 225 µs 的等待地板；
  单个比值低于 1.00x 需要与同一条记录里对照侧的绝对时间一起读，否则只是宿主窗口漂移。
- `layer_norm[64x1024]` 与 `constant_pad_nd[64x64x64]` 两例没有对照计时（在基准的
  显式跳过清单内），因此不参与总体几何平均。

macOS arm64 轮子默认带 MPS 后端。

```bash
# CPU 轮子（PyPI；macOS 轮子内置 MPS 后端）
pip install tensorplay==1.2.0

# CUDA 13.0 轮子
pip install tensorplay==1.2.0 \
  --index-url https://download.tensorplay.cn/whl/cu130/ \
  --extra-index-url https://pypi.org/simple

# ROCm 轮子（AMD / HIP，rocm72-multiarch）
pip install tensorplay==1.2.0 \
  --index-url https://download.tensorplay.cn/whl/rocm72-multiarch/ \
  --extra-index-url https://pypi.org/simple
```
