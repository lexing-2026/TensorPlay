# 亮点 Highlights

- **macOS MPS 后端正式成形**：从设备 / 分配器骨架扩展到完整 LLM 训练推理栈——
  Metal shader 库、flash attention（prefill / 单遍 decode / 两遍 decode）、SDPA 路径选择、
  嵌入与 embedding bag、RMSNorm 前向/反向、融合优化器（Adam / AdamW / SGD foreach）、
  AMP 梯度缩放、top-k 采样、随机工厂、稀疏 COO、量化算子、GEMM / 卷积一应俱全；
  macOS 轮子默认启用并配备独立算子基准与 CI 性能下限。
- **低比特量化全链路**：原生 INT4 / INT2 / 1-bit 权重算子与 `8da4w` / `8da2w` / `8da1w`
  行列量化内核，AWQ 扩展到 int2，FP8 动态推理，BitNet b1.58 三元权重与 STE 训练；
  直接 int4 tensor-core GEMM（pipelined 与 mma 双路径）默认改走 cuBLAS 反量化通道。
- **量化算子族成体系（CPU + CUDA）**：packed affine dtype、量化线性 / 卷积 / 池化 /
  归一化 / 激活 / 嵌入 / 循环 / 张量运算全覆盖；eager QAT、FX graph-mode
  （`prepare_fx` / `convert_fx` / `fuse_fx`）、后端配置框架与融合注册表齐备，
  并提供 one-call 自动量化工作流。
- **ROCm 成为默认发布通道**：CDNA MFMA flash attention 与 wave64 安全 WMMA 回退，
  HIP 工具链构建修复成体系；ROCm 轮子进入 release / nightly 默认矩阵并发布到
  独立 ROCm pip 索引。
- **可解释性套件 `tensorplay.lumen`**：经典归因（IG / DeepLIFT / LRP / SHAP / TCAV）、
  稀疏自编码器、交叉层 transcoder、attribution graphs、feature circuits、logit lens、
  因果追踪与激活修补，以及图重写引导的反向传播与编译消融执行。
- **量子模拟模块 `tensorplay.quantum`**：状态向量与密度矩阵、门表线路与变分拟设、
  测量与采样、噪声信道、Lindblad 主方程、参数位移梯度，配套本地门 / 振幅概率 /
  Kraus / Pauli 信道等原生内核。
- **脉冲神经网络 `tensorplay.snn`**：融合 LIF / IF 神经元内核、15 个原生代理梯度、
  多步 BPTT、`SpikingConv2d` / 时间折叠批归一化等深层 SNN 模块。
- **评估套件 `tensorplay.metrics`**：分类 / 回归 / AIGC / 音频 / 检索等域指标，
  状态式 `Metric` 与函数式双形态；融合双输入归约让 MSE / MAE 在 CPU 上数倍加速。
- **编译器符号形状下沉**：符号尺寸贯穿 Stax 捕获、正向/反向图复用、视图与方差梯度，
  动态布局以运行时守卫落地；稀疏 addmm 自动微分与嵌入稀疏反向路由补齐。
- **Vulkan 教学后端增强**：显存池 + vec4 广播二元算子、GRU / LSTM 推理、layer_norm
  反向（组合矩单趟）、pooling 反向、randn / erf / native_dropout 等新算子。

# 新特性 New Features

## macOS MPS 后端

- **后端骨架**：设备 / 分配器 / 工厂 / copy / add，`tp.mps.is_available()` 入口；
  macOS wheel 默认启用。
- **基础算子面**：逐元素、激活、归约、随机工厂、`cat` / `stack` / `embedding`、BLAS、
  `all` / `any`；损失族（mse / l1 / smooth_l1 / huber / bce / nll）；归约 / 视图 / 池化 /
  归一化 / 索引 / 量化算子；`batch` / `group` norm、conv2d、`argmax` / 极值归约。
- **Metal shader 库与量化**：shader 化 int4 / int8 量化矩阵乘、per-channel
  quantize / dequantize、`make_per_channel_quantized_tensor`、per-tensor affine 量化填充。
- **稀疏 COO 后端**：工厂、`coalesce`、格式转换、mm、add/mul、sum、addmm。
- **排序与结构算子**：scan、sort、bucketize、dropout、三角算子全部 shader 化。
- **LLM 推理/训练栈**：RMSNorm（含 fused 反向）、embedding 前向/反向、embedding bag、
  融合优化器（Adam / AdamW / SGD foreach）、top-k 采样、SDPA 路径选择、flash attention
  prefill、单遍 / 两遍 decode attention、masked SDPA。
- **GPU 随机工厂**：rand / randn / arange / eye / randint / linspace / logspace /
  randperm / multinomial 直接落到 GPU shader，生成器一路传到内核。
- **AMP**：梯度缩放与非有限检查内核。
- **高级内核**：M5+ cooperative-tensor GEMM 与 conv2d、张量相等性检查。
- **性能路径**：索引类算子迁移到 Metal shader，降低 CPU 桥接开销。

## Vulkan 后端

- 新算子：GRU / LSTM 推理、`narrow`、randn 工厂、erf、`native_dropout`、激活反向
  （elu / selu / softplus）、max / avg pool2d 反向、layer_norm 反向（组合矩单趟）。
- 性能：显存池 + vec4 广播二元算子、工作组扩大、设备显存不足时回退线性存储。
- 修复：任意形状索引的 embedding、池化几何归一化、layer_norm 崩溃与仿射/归一化模式、
  设备广播、autograd 反向与优化器路径。

## 低比特量化

- **权重专用算子**：INT4 weight-only（含 `8da4w`）、INT2 / 1-bit rowwise 量化内核与
  `8da2w` / `8da1w`、packed affine dtype（quint2x4 等）、四比特嵌入权重。
- **AWQ / FP8**：AWQ 扩展到 int2；FP8 动态推理与原生 FP8 量化原语、训练模块。
- **BitNet**：1-bit 仿射 dtype、b1.58 三元量化、`BitNetLinear` 直通估计器训练、
  权重子类与 `quantize_` API。
- **GEMM 路径**：直接 int4 tensor-core mma / pipelined GEMM 内核；默认走 cuBLAS
  反量化路径；int8 `_int_mm` 经 cuBLASLt tensor core；AVX2 BF16 int4 内核。
- **前端工作流**：one-call 自动量化、generic `intx` weight-only 配置、缓存解包模式、
  int2 / intx 反量化广播、INT8 weight-only 量化训练与混合精度训练注册表。

## 量化算子族（CPU + CUDA）

- **张量运算**：量化张量加 / 乘 / 比较 / 归约 / 视图 / 拷贝 / dtype 转换。
- **模块面**：量化 Linear / Conv / MaxPool / Hardtanh / dropout / softmax / prelu、
  融合 Linear-LeakyReLU / Linear-Tanh / Conv-Add 内联模块。
- **归一化与嵌入**：量化批归一化、embedding（含四比特权重）、循环门（GRU / LSTM /
  RNN）与持久化单元参数。
- **packed 执行**：packed int4 与 wrapped 量化线性、packed 存储 / 网格在设备转换与
  拷贝间保留、packed affine 检查点往返。
- **eager QAT**：observer / fake-quantize / qconfig 默认工厂、quant type 枚举、
  eager 转换、归一化融合、嵌入与动态 QAT 训练模块、检查点保存/恢复。
- **FX graph-mode**：`prepare_fx` / `convert_fx` / `fuse_fx` 工作流、后端配置框架与
  原生后端配置、融合方法注册表与自定义融合 API、reference 量化模块与
  `from_reference` 转换路径、稀疏量化线性。
- **CUDA 扩展**：量化算子族与 oneDNN qint8 卷积。
- **低比特推理加速**：AVX2 BF16 int4 内核、int8 mm 融合 rowwise 量化、
  单趟 rowwise quantize、量化归约 / 池化 / 嵌入 / softmax / 循环门向量化。

## 可解释性（tensorplay.lumen）

- 经典归因：IntegratedGradients、DeepLIFT、LRP、SHAP、TCAV（概念激活向量）与对抗验证。
- LLM 工具：稀疏自编码器（SAE 特征学习）、交叉层 transcoder、attribution graphs、
  feature circuits、logit lens、因果追踪、激活修补与注意力图。
- 图分析：真实子图匹配的 fx 数值套件、图重写引导反向传播、编译消融执行、
  模型分析 API、特征电路与跨层分析。
- 可视化：论文风格多层注意力图、token 高亮、共享 colorbar。

## 量子模拟（tensorplay.quantum）

- 模块面：状态向量与密度矩阵、门表线路、变分拟设、测量 / 采样 / 读出、噪声信道、
  Lindblad 主方程、参数位移梯度、化学 ansatz 门族（受控平方根、双受控相位等）。
- 内核：本地门与振幅概率、Pauli 信道、Kraus 多比特信道、振幅编码、密度矩阵本征态
  混合分解、Pauli 期望 / 边缘化、Trotter 演化、梯度的位移规则。
- 集成：量子内核与既有算子 / autograd 协同，测量保留在记录图内。

## 脉冲神经网络（tensorplay.snn）

- 融合 LIF / IF 神经元算子、15 个原生代理梯度、`grad_v_reset`、逐神经元 `v_reset`、
  ATan / Erf 代理、自适应 SNN 模块、多步并行与浮点代理梯度加速。
- 深层模块：`SpikingConv2d`（含 reset 与端到端训练循环）、时间折叠
  `SpikingBatchNorm1d/2d`、`SeqToANNContainer`、`SpikeLinear`。

## 评估指标（tensorplay.metrics）

- 分类 / 回归 / 检索 / 名义 / 遥感 / 音频 / AIGC（FID、KID、Inception Score、LPIPS）/
  图像（PSNR、SSIM）指标；曲线、一致性与距离分类指标；曲线绘图。
- 融合归约：`sum_squared_error` / `sum_abs_error` 单趟向量化，回归指标显著加速。
- 包装器：`MetricCollection`、`MetricTracker`、运行指标、classwise / multioutput /
  min-max / bootstrap / multitask 包装器；外部依赖指标懒加载。

## 稀疏与编译器

- 原生 `sparse.addmm`、`sampled_addmm`、`spmm_reduce`、`spsolve`；`sparse_mm_reduce`
  autograd 导数；`to_sparse_csr` 与稀疏 `mul.Scalar`。
- 编译器：embedding 稀疏反向路由到稀疏梯度；稀疏 addmm 与布局转换的 autograd；
  符号尺寸在视图 / 方差梯度、原生梯度公式、Stax 捕获与正向/反向图复用中保留；
  动态布局以运行时守卫降低；输入 stride 特化编译区域。

# 改进 Improvements

- MPS 后端按算子族组织为独立 Objective-C++ / Metal 文件，沿用仓库"每文件一族内核、
  一个注册宏"的可读结构，便于学习并行计算与原型验证。
- 前端热路径：低比特反量化广播、缓存解包模式；INT8 权重前向保证 contiguous。
- 量化内核：整型向量裁剪、浮点斜率 PReLU、量化窗口复用与 packing 向量化、
  空间量化均值融合、体素池化向量化、尾块精度保持。
- 稀疏：CPU `sparse_addmm` 非零循环 4x 展开、per-ISA 向量化、量化嵌入 packing 优化。
- 随机 / 生成器：量子模块中的 Haar 随机酉与状态、全局相位读取。

# 性能 Performance

测量方法沿用"静默机器 min-of-window"，具体数值以发布前基准为准（待补）；以下为本轮
已落地的改进方向与依据：

- **MPS**：索引类算子从 CPU 桥接迁到 Metal shader；随机工厂全部 GPU 化；
  融合优化器 / RMSNorm / flash attention 直接以 GPU 内核执行。
- **Vulkan**：显存池复用 + vec4 广播二元算子减少分配与启动开销；layer_norm 反向以
  组合矩单趟完成；工作组扩大提升占用。
- **低比特 GEMM**：int4 默认走 cuBLAS 反量化路径；pipelined direct int4 tensor-core
  与 mma 内核；int8 `_int_mm` 经 cuBLASLt tensor core；AVX2 BF16 int4 内核。
- **量化算子向量化**：int8 mm 融合 rowwise 量化与 rescale、单趟 rowwise quantize、
  量化归约 / 池化 / 嵌入 / 软最大 / 循环门 / cat 的 SIMD 路径、CPU `sparse_addmm`
  非零循环 4x 展开与 per-ISA 分派。
- **指标**：融合双输入归约单趟计算 SSE / SAE，MSE / MAE 相对参考实现数倍加速
  （AVX2，8 线程，详见 README Benchmarks 节）。

# 安装 Installation

```bash
# CPU 轮子（PyPI；macOS 轮子内置 MPS 后端）
pip install tensorplay==1.2.0

# CUDA 轮子（cu124 / cu126 / cu130）
pip install tensorplay==1.2.0 \
  --index-url https://download.tensorplay.cn/whl/cu130/ \
  --extra-index-url https://pypi.org/simple

# ROCm 轮子（AMD / HIP，rocm72-multiarch）
pip install tensorplay==1.2.0 \
  --index-url https://download.tensorplay.cn/whl/rocm72-multiarch/ \
  --extra-index-url https://pypi.org/simple
```
